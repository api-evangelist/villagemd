# VillageMD

> VillageMD is a Chicago-based, value-based primary care organization that operates and
> supports physician practices across the United States through its Village Medical,
> Village Medical at Home, Summit Health, CityMD and Starling Physicians operating
> companies. It delivers care — free-standing practices, in-Walgreens practices, home
> visits and virtual visits — rather than selling software. VillageMD publishes no
> developer portal, no API documentation, no machine-readable specification, no SDK and
> no /.well-known/ discovery documents. Its clinical record and patient-facing digital
> surface run on athenahealth, so the only machine-readable health APIs touching its
> patients are athenahealth's certified FHIR R4 APIs, which athenahealth — not VillageMD
> — operates and documents. This file is generated by API Evangelist from public
> sources; it is not published by VillageMD.

## API surface

- None published. No OpenAPI, Swagger, GraphQL, AsyncAPI, webhook catalog, MCP server,
  A2A agent card, Postman collection, SDK, CLI or developer portal exists on any
  VillageMD host as of 2026-08-05.
- Patient health-record access is delivered through athenahealth: practice-specific
  patient portals (e.g. `https://21533-1.portal.athenahealth.com/`) and the athenaPatient
  mobile experience shipped as the Village Medical app.
- [athenahealth API documentation](https://docs.athenahealth.com/api/guides/overview) —
  the operator of the certified FHIR R4 surface behind Village Medical practices. This is
  athenahealth's developer program, not VillageMD's.
